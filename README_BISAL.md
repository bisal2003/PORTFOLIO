## 📞 Need Help?

### Common Issues:

**Images not showing?**
- Check file names match exactly (case-sensitive)
- Verify images are in correct folder
- Check browser console for errors (F12)

**Resume not downloading?**
- Ensure file is named exactly "resume.pdf"
- Check it's in public folder (not public/images)
- Test the link directly: `http://localhost:3000/resume.pdf`

**Build errors?**
```bash
# Clear cache and rebuild
rm -rf .next
npm run build
```

**Links not working?**
- Verify URLs in component files
- Check for typos in GitHub username, etc.
